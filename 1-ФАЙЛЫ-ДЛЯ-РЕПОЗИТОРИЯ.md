# Файлы, которые нужно занести в репозиторий

Пометка **1** = файл должен попасть в репозиторий. Это весь проект —
30 файлов, ровно то, что лежит в git (проверено командой `git ls-files`).
Остальное (.venv, базы данных, кэши) в репозиторий НЕ попадает:
git сам их игнорирует благодаря backend/.gitignore — ничего удалять не нужно.

## Что в репозиторий НЕ заносится (git пропустит сам)

- `backend/.venv/` — виртуальное окружение, пересоздаётся командами из README
- `backend/data/users.db` — база пользователей (личные данные, создаётся сама)
- `backend/.pytest_cache/`, `__pycache__/` — служебный кэш тестов и Python
- `backend/.env` — появится, если скопируешь `.env.example`; содержит секреты

## Как занести в репозиторий

Вариант 1 (правильный): в терминале из папки Recept_zina —
`git remote add origin <адрес-репозитория>` и `git push -u origin main`.

Вариант 2 (руками через сайт GitHub): создаёшь файлы в веб-интерфейсе
(Add file -> Upload files) и перетаскиваешь файлы из чек-листа выше,
сохраняя пути папок (backend/app/..., backend/data/... и т.д.).
